# LeetCode #151 — Reverse Words in a String

* **Difficulty:** Medium
* **Language:** Python
* **Runtime:** 0 ms
* **Memory:** 12.54 MB
* **Runtime Beats:** 100.00%
* **Memory Beats:** 36.47%

## Approach

1. Split the string into individual words using `split()`.
2. Reverse the list of words using `reverse()`.
3. Join the reversed words with a single space using `" ".join()`.
4. Return the resulting string.

## Complexity

* **Time:** O(n)
* **Space:** O(n)
